Have a Dice Day! is an interactive 3D dice tower developed as a final project for the Interactive Graphics course at Sapienza University of Rome.



The application simulates the roll of a die through a customizable-style tower. The dice movement is handled through a physics simulation, while the tower collapse and other visual effects are procedurally animated.



The application includes a standard D6 mode and a bonus Zargos Mode, which allows the user to roll non-textured D8, D12 and D20 dice
